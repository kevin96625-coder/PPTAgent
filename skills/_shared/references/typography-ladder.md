# 排版字号阶梯(Typography Ladder)

> **来源标注:通用设计规范 / 非原帖 / 待复核。** 本文件把 `svg-generator.md` 既有的字号区间收敛成 7 级离散阶梯,属业界通用排版规范,**不是**任何单一原始帖子的规定。各 style YAML 的 `typography_ladder` 块是该 style 的单一来源;本文档是跨 style 的设计说明与生成引导。

## 1. 七级阶梯(base px @ scale 1.0)

阶梯值是 **scale=1.0 时的基准 px**。实际渲染字号 = `base × typography.scale × (slide_type heading_scale 覆盖)`。例如封面 `heading_scale=1.3` 时,`h1` 实际为 `64 × 1.3 = 83.2px`。

| 角色 | base px | 用途 |
|------|---------|------|
| `h1` | 64 | 封面 / 区隔大标题、hero 数字(原 48–72 区间) |
| `h2` | 40 | 页面主标题(原 36–44 区间) |
| `h3` | 28 | 卡片标题 / 小节标题(原 24–32 区间) |
| `body` | 18 | 正文(社区反馈下限 16,取 18) |
| `label` | 15 | 标签 / 坐标轴 / 图例(≥14 floor,取 15) |
| `caption` | 14 | 脚注 / 出处(≥14) |
| `micro` | 12 | 页码 / 角标 |

## 2. 使用规则(生成引导)

- **就近选档**:正文与标题应就近落到上述某一档,不要随手取任意中间值。少量特例(如 hero 大数字)可偏离——阶梯是推荐档位,不是唯一合法值。
- **收敛种数**:一页内不同字号种数尽量控制在阶梯 7 档以内。字号种数过多本身就是视觉噪声(`type-scale` 校验器的首要稳健信号)。
- **14px 下限**:`caption` 及以上一律 ≥14px。**`micro`(12px)是唯一允许 <14px 的角色**,仅用于页码 / 角标(`data-role="page-number"` 或 `data-role="label"`),与 M2.6 的 label/footnote 12px floor 一致,不冲突。
- **装饰文本**:纯装饰、超大水印类文本应标 `data-decorative="true"`,校验器会跳过其字号统计。

## 3. CJK 行高注意

中日韩(CJK)字形方正、视觉重心偏满,等字号下比拉丁字母更"挤"。**CJK 文本块的行高(line-height)建议在拉丁基准上 +20%**(例如拉丁 1.4em → CJK 1.68em),避免行间过密。字号本身仍按上表阶梯选取,只调行高,不调字号档位。

## 4. 与校验器的关系

- `lib/type-scale.js` **只读分析**:统计不同字号种数 + 偏离档位的字号,产**软警告**(advisory)。
- 它**绝不**自动改写字号、**绝不**阻塞、**绝不**触发重画。off-ladder 在未知有效 scale 时降级为 best-effort 纯信息。
- 真正的价值在**生成期**:让 slide 一次就按阶梯画对;校验只是事后给编排器 / reviewer 的廉价确定性信号。
